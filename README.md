# HighLight
Pendeteksian Manusia dalam Kondisi Pencahayaan Rendah Menggunakan Histogram Equalization dan Pemrosesan Citra Digital.

Proyek ini berfokus pada pengolahan citra digital untuk mendeteksi keberadaan manusia dalam gambar atau video dengan pencahayaan minim. Dengan menggabungkan teknik Histogram Equalization, deteksi HOG (Histogram of Oriented Gradients), dan beberapa alat bantu pemrosesan citra lainnya, aplikasi ini dapat meningkatkan visibilitas dan efektivitas deteksi objek manusia dalam kondisi gelap.

## Cara Menjalankan Program
Jalankan main.py untuk memulai program.
```
py main.py
```
Pastikan semua dependensi telah diinstal sebelum menjalankan program.

## Dependensi / Modul yang Digunakan
Proyek ini menggunakan beberapa pustaka Python populer, antara lain:

- sys – Modul standar Python untuk mengakses variabel dan fungsi sistem.

- cv2 (OpenCV) – Untuk pemrosesan gambar dan video.

- numpy – Untuk manipulasi array numerik.

- PyQt5 – Untuk membangun antarmuka pengguna grafis (GUI).

    - QtCore, QtWidgets, QtGui, loadUi – Komponen dari PyQt5 yang digunakan dalam   pengembangan UI.

- matplotlib.pyplot – Untuk menampilkan grafik atau visualisasi histogram citra.

- pandas – Untuk manipulasi dan analisis data, seperti membaca file CSV.

- imutils – Modul tambahan yang menyederhanakan beberapa operasi OpenCV, seperti resize gambar.
